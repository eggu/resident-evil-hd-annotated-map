# 출처와 배포 권리

[한국어](10-sources.md) | [English](10-sources.en.md) · [Index](README.md)

지도 데이터(좌표, 방 대응, 획득 플래그, 출현 조건)는 합법적으로 소유한 게임에서 얻었습니다. 게임 실행 파일, 아카이브, 세이브는 포함하지 않습니다. Resident Evil / Biohazard와 관련 이름, 캐릭터, 아이템 디자인, 게임 데이터는 Capcom Co., Ltd.의 상표이자 저작물입니다. 이 모드는 비공식 팬 모드이며 Capcom과 관련이 없고 승인받지 않았습니다.

| 자료 | 용도 |
| --- | --- |
| [Evil Resource](https://www.evilresource.com/) | 방 이름과 내용 대조. 원문과 이미지는 포함하지 않음 |
| [RE3 Annotated Map](https://github.com/eggu/resident-evil-3-annotated-map) | 타자기와 아이템 상자 아이콘 |
| [Pretendard](https://github.com/orioncactus/pretendard) | 지도 글자와 범례 글꼴 (SIL OFL 1.1) |
| [Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader) | 포함된 ASI 로더 v9.7.4 (MIT) |
| Zig (`ziglang`), Clang, Pillow | 별도로 설치하는 빌드·테스트 도구, 각자의 라이선스 |

아이콘은 이 모드를 위해 AI 도움으로 만든 픽셀 아트입니다. 아이템 아이콘은 게임 인벤토리 이미지를 스타일 변환했고, 적 얼굴과 배지는 같은 스타일로 생성했습니다.
