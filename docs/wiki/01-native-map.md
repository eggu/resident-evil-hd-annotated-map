# 원작 지도와 표시 범위

[한국어](01-native-map.md) | [English](01-native-map.en.md) · [Index](README.md)

게임 자체의 지도에 주석을 겹칩니다. `8`은 방문한 방 → 공개된 방 → 모든 방을 순환합니다. 모든 방은 미방문 윤곽과 문 선을 보여 주지만 층 탭은 원작 그대로이므로, 아직 도달하지 못한 층이나 지역으로 바꿀 수는 없습니다. 주운 아이템과 완료한 퍼즐은 지도에서 사라집니다.

처음 실행하면 영어, 방문한 방 범위, 방 이름만 켜진 상태입니다. 범례에 현재 상태가 표시됩니다.

| 키 | 동작 |
| --- | --- |
| `0` | 주석 전체 켜기/끄기 |
| `1` | 방 이름 |
| `2` | 잠긴 문과 필요한 열쇠 |
| `3` | 핵심 아이템 |
| `4` | 문서·지도 |
| `5` | 퍼즐 |
| `6` | 이벤트 (스포일러가 되는 이야기 장면, 처음에는 숨김) |
| `7` | 일반 아이템 |
| `8` | 적·크림슨 헤드 (적 표시 중 길게 누르면 남은 시간 켜기/끄기) |
| `9` | 표시 범위 |
| `\`(₩) | 한국어 / English |
| `-` · `+` | 이름 크기 (50–150%) |
| `[` · `]` | 이름 불투명도 (10–100%) |
| `Shift` + `-` · `+` | 아이콘 크기 (50–200%) |
| `Shift` + `[` · `]` | 아이콘 불투명도 (10–100%) |
| `H` | 아이템 이름 3단계: 모두 → 일반 아이템 제외 → 끔 (처음에는 끔) |
| `~` | 범례 접기 |
| 공격 버튼 | 지도 2배 확대 켜기/끄기 |
| 방향 (확대 중) | 지도 이동 |

지도를 다시 열면 1배로 돌아갑니다.

확대하면 방과 문 표시는 2배가 되고 플레이어 표시는 원래 크기로 지도와 함께 움직입니다. 층 이름은 범례 위로 옮겨지며, 원작 안내 UI는 숨겨지고 모든 타자기와 아이템 상자가 방 안 실제 위치에 아이콘으로 표시됩니다. 축소 중에는 원작 지도에 표시되지 않는 것만 그립니다.

## 원작 데이터 참고

주소는 `verification/source-snapshot.json`의 `game_exe_sha256`이 가리키는 `bhd.exe` 기준입니다.

| 주소 | 의미 |
| --- | --- |
| `0xc3d0f8` | 지도 객체 vtable, 슬롯 0–9에서 지도 객체를 잡음 |
| 지도 객체 `+0x6268` / `+0x626c` | 지역 / 층 |
| 지도 객체 `+0x629c` | 지도 또는 아이템 상자 화면 |
| 지도 객체 `+0x6090` | 지도 오프셋 |
| `[0xd5a048]` `+0xb8` / `+0xbc` | 백버퍼 안의 16:9 화면 크기 |
| `0x555377` / `0x5543b1` | 모든 방 범위에서 바꾸는 윤곽 / 문 선의 뱅크 7 플래그 검사 |
| `0x5561d0` | 지도 그리기 호출 39곳, 확대 시 분류 |
| `0x4d9230` | 패드 입력(누름 유지) |

원작 2D 출력은 `48 + .9x`, `36 + .9y`에 지도 오프셋을 더한 값입니다.
