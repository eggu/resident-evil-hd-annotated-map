# 데이터와 표 읽기

[한국어](02-data-pipeline.md) | [English](02-data-pipeline.en.md) · [Index](README.md)

스포일러 포함. 현재 src/labels.h의 조건별 표식 행이며 고유 아이템 수나 동시 출현 수가 아닙니다. 런타임 추가 판정은 아래 설명을 참고하세요.

좌표, 방 대응, 획득 플래그, 출현 조건은 합법적으로 소유한 게임에서 얻었습니다. 방 이름과 내용은 [Evil Resource](https://www.evilresource.com/)와 대조했습니다.

| 데이터 | 파일 |
| --- | --- |
| 표식과 글자 그림 | `src/labels.h` |
| 출현 규칙과 아이템 게이트 | `src/item_state.h` |
| 퍼즐 보상 규칙 | `src/reward_rules.h`, `src/reward_state.h` |
| 레베카 구출 | `src/rescue_state.h` |
| 같은 층의 확장·통합 구역 | `src/section_rules.h` |
| 크림슨 헤드 그림과 대체 표 | `src/crimson_data.h` |
| 적 기록 | `src/enemy_rec.h` |
| 읽기 쉬운 방·표식 메타데이터 | `data/rooms.json`, `data/labels.json` |
| 아이콘 | `assets/icons/` |

빌드는 고정된 헤더를 컴파일합니다. JSON을 고쳐도 헤더는 다시 만들어지지 않습니다. 좌표와 표식 생성기는 게임 파일을 읽으므로 이 저장소에 없으며, 해당 행은 헤더에서 직접 고칩니다. 글자 그림은 `tools/render_labels.py`로 다시 그립니다. 이 위키의 표는 `python tools/gen_wiki.py`로 생성하며 게임 파일이나 네트워크가 필요 없습니다.

`src/item_state.h`의 `item_gates`는 게임의 방별 "아이템 전부 획득" 판정에서 나왔습니다. `tools/item_gates.py`가 합법적으로 소유한 게임에서 얻은 분석용 메모리 이미지로 이 표를 출력합니다. 이 조건은 필요조건이지 완전한 출현 규칙이 아니므로 직접 확인한 규칙을 함께 둡니다. 판정 안의 보조 호출은 참으로 치고, 도달할 수 없는 결과에는 게이트를 더하지 않아 판단하지 못한 아이템은 계속 표시됩니다.

## 표 읽기

- `Map`은 `지역:층` 번호입니다. 층 이름이나 출력 해상도가 아닙니다.
- `Cell`은 게임의 방 번호 0–153, `Room ID`는 방 코드입니다.
- `x,y`는 지도 기준 좌표입니다. 게임은 이 좌표에 확대·이동과 화면 크기를 적용합니다. 한국어와 영어 표식의 좌표가 다를 수 있고, 현재 방의 아이템은 실행 중에 실제 위치로 옮겨질 수 있습니다.
- `캐릭터`와 `난이도`는 행을 제한할 때만 표시합니다. `—`는 제한이 없다는 뜻입니다. 난이도 분류는 매우 쉬움·쉬움, 보통, 어려움입니다.
- `출현 조건`의 `조건부`는 게임이 추가 조건을 검사하지만 사람이 쓴 설명이 없다는 뜻입니다. `—`는 범위·획득 판정 외의 추가 조건이 없다는 뜻입니다.
- 뱅크와 플래그 번호는 게임의 값 그대로입니다. 이름이 없는 번호의 이야기상 의미는 적지 않았습니다.
- 표식 행은 범위, 층, 획득·해제 상태도 함께 통과해야 보입니다.
