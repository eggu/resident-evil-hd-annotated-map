# Development

## Build

Python 3.11 or newer. The compiler is `ziglang==0.14.1`, installed from `requirements.txt`; the target is `x86-windows-gnu`.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python build.py
```

The result is `dist/RE1-HD-Annotated-Map-<version>.zip` and `dist/build-report.json`. Building does not read game files or the network.

Tests also need Clang and Pillow:

```sh
python -m pip install -r requirements-test.txt
python build.py --test
```

## Layout

- `src/re1_mapnames.c`: the ASI. Direct3D 9 `EndScene` overlay and native map hooks.
- `src/zoom.h`: 2x map view arithmetic. `src/exe_check.h`: supported EXE guard. `src/hold_key.h`: tap and hold on one key, and the toggle rest (debounce).
- `src/marks.h`: mark and item-name placement, the RE0 HD rules (tiers, weights, slots, drop and badge rules); `tests/test_marks.py`.
- `src/legend_text.h`: generated by `tools/render_legend.py` (icon size and opacity readouts for Shift and Ctrl, `[H]` in three states, `[~]`, `[\]` language). `src/colors.h`: the category colour table (INI `[Colors]`) and its parser. `src/name_lines.h`: generated by `tools/gen_name_lines.py`, the line bands of every multi-line name raster for the aligned drawing.
- `src/synth_marks.h`: puzzle marks with no label row (Rec Room lamps, Medical Room passcode door), their visibility and the lit lamps' eye symbols (icons 97-99, drawn by `tools/render_symbols.py` into `assets/icons/symbol-eye-*.png`); their names are in `item_name_text.h` (ids 1001+).
- `src/item_name_text.h`: generated by `tools/render_item_names.py` (the ordinary items' names in #B4A7D6, both languages, from `data/item_names.json`, plus the label-to-item-id table); shown with [H] by the lowest tier of `marks.h`.
- `src/save_points.h`: typewriter and item box positions (aev types 6 and 8) from `tools/extract_save_points.py`; `tools/extract_aev.py` reads a room's aev records.
- `src/{item,rescue,reward}_state.h`: state predicates. `item_state.h` includes the item gates.
- `src/enemy_rec.h`: recorded enemy spawns and the `RE1HD.AnnotatedMap.enemies.dat` format.
- `src/{labels,crimson_data,reward_rules,section_rules}.h`: generated data, committed as build inputs.
- `tools/render_labels.py`: redraws the marker-name and legend text in `labels.h` and `crimson_data.h` with `fonts/Pretendard-Medium.otf`. Room names are drawn by `tools/layout_room_names.py`. Marker names, room names, legend rows and item names are drawn white with a dark outline; the run time multiplies them by the category colour. `tools/rebuild_legend.py` rewrites the legend's category rows ([0]–[8], scope [9]) and the two counts.
- `tools/apply_name_rules.py`: applies the shared name rules to the `labels.h` comments (wrap at 8 characters, Korean '의' with `verification/korean-particle-keep.json`), turns ordinary weapon rows into key items and fixes the legend wording. Then run `rebuild_legend.py`, `render_labels.py --kinds 1-6`, `layout_room_names.py`, `render_item_names.py`, `render_legend.py`, `gen_name_lines.py` and `gen_wiki.py`.
- `tools/gen_wiki.py`: generates the table pages of `docs/wiki` from the committed data; `--check` compares them. The README, `01`, `02` and `10` pages are written by hand.
- `tools/item_gates.py`: prints the `item_gates` table from an analysis memory image derived from a legally owned copy of the game. Needs capstone, which is not in `requirements.txt`.
- `data/`: readable room and marker metadata.
- `assets/icons/`: 32 px sprites; `tests/test_icons.py` checks they match `labels.h`.
- `packaging/`: default INI, ZIP guide and Ultimate ASI Loader.

The generators for item and marker coordinates read a legally owned game and are not part of this repository. Change those rows in the headers directly and run the tests.

## Simplified Chinese (zh_cn)

zh_cn is the third language slot (`Language=zh`, `\` cycles en → ko → zh). It reuses every Korean label row (positions, conditions,
legend layout) and swaps only the raster: `src/labels_zh.h` (`zh_text[]`, image range `ZH_FIRST`) names the Korean row each Chinese
raster replaces; room names carry their own anchor. Item names (`item_name_text` lang 3) and `legend_text` (third block) have their
own zh rows. Text is `data/zh_cn.json` (keyed by the Korean source text; names follow the Pujia Chinese patch), the font Source Han Sans SC
(SIL OFL 1.1), bundled as subsets.

```sh
python tools/subset_zh_fonts.py        # after changing data/zh_cn.json; full fonts in local/fonts/ (ignored)
cd tools && python render_legend.py && python render_item_names.py && python gen_name_lines.py && python render_zh.py
python build.py --test                 # tests/test_zh.py checks coverage, fonts and the runtime wiring
```

`tools/render_zh.py` places the Chinese room names with `layout_room_names.py`'s search and check (`data/room_names_zh.json`) and stops
on any missing translation. Run it after `render_labels.py` / `layout_room_names.py` whenever `labels.h` changes.

## Room shapes and room names

Room names are placed at build time on each room's real shape (the RE0 HD rules: pole of inaccessibility, smallest rooms first, leaders for corridors, 150% wrap, room names never overlapping on a floor). To regenerate:

```sh
python tools/extract_room_shapes.py "<game folder>" --dump local/room-shapes   # reads bhd.exe and map_st01..05.arc, read only
python tools/layout_room_names.py                                            # rewrites the room-name rows and rasters in src/labels.h
python build.py --test
```

- `tools/extract_room_shapes.py` writes `data/room_shapes.json`: per room its map position, area, floor, texture page and rectangle from the static room table in `bhd.exe` (RVA `0x8c8e00`, 154 x 96 bytes), and the filled silhouette from the flat map texture `stNN_1P_ID_HQ` (TEX v0x9d, BC3) in `nativePC/arc/id/e_rom/subscr/map_stNN.arc`, as row runs. It checks the EXE hash and records every source's SHA-256 and the date. `--dump` writes the decoded textures under `local/` (ignored); game images are never committed. Areas 5 rooms 31, 37, 123, 124, 142 and 150 (lifts) have no map rectangle.
- Canvas = `48 + 0.9 * (map + texel * (0.9375, 0.8035))`. `tests/test_room_shapes.py` proves it: the item markers lie in their rooms and stop doing so with a 5-unit offset or a 5% smaller scale, and rooms tile a floor with an overlap that doubles at a 5% larger scale.
- `tools/layout_room_names.py` places the names (`tools/room_geometry.py` holds the shapes), stops on any violation of its standalone check (anchor in its room, leader axis-aligned and at most 60 units, outside names on no room, no overlaps), redraws only the room-name rows and writes the layout to `data/room_names.json`. A row's `x, y` is its anchor and `ax, ay` the anchor in the raster; the runtime keeps the anchor fixed when the name size changes. The output is byte-identical on a re-run (`tests/test_room_names.py`).
- `tools/render_labels.py` no longer touches room names.

## Native addresses

All addresses are for the `bhd.exe` whose SHA-256 is `game_exe_sha256` in `verification/source-snapshot.json`.

- Map object vtable `0xc3d0f8`: slots 0–9 capture the map object. `+0x6268` area, `+0x626c` floor, `+0x629c` map or item box view.
- Renderer `[0xd5a048]`: `+0xb8` and `+0xbc` are the 16:9 picture size inside the back buffer. `fit_screen` centres the overlay in it.
- Native 2D output is `48 + .9x`, `36 + .9y`, plus the map offset `+0x6090`.

## Item gates

`item_gates` in `src/item_state.h` lists when a pickup can exist. It comes from the game's per-room "all items taken" predicates around `0x4830b0`. These are necessary conditions rather than full spawn rules, so the hand-verified rules stay beside them. Helper-call literals count as true, and unreachable results add no gate, so unresolved items stay visible.

## Scope

All-rooms scope redirects the two bank-7 flag tests at `0x555377` (outlines) and `0x5543b1` (door lines). Floor tabs stay native, so it never opens a place the player has not reached.

## Map zoom

All 39 map calls to `0x5561d0` are sorted in `re1_mapnames.c`:

- Rooms and door marks scale 2x. The paper scales from a clean part of its texture.
- The player marker moves with the map at native size.
- The floor name is a GUI text object (`[[0xcf30d8]+0x30]+0x250`, position `+0x80`). It moves above the legend and goes back before other screens use it.
- The dial, compass, legend, buttons and typewriter and item box callouts are skipped; `build_save_icons` draws those rooms as icons.

Directions come from the pad at `0x4d9230` (held). `0x552b1b` is replaced so zoomed directions pan instead of changing floors. The same hook reads the Attack button (zoom): the pad mask in the scheme block at config `+0xba0`, slot `+0x24`. It has no slot in the game's keyboard table, so the keyboard side reads the left mouse button. A left click on a map button stays the game's (`0x4ddf40`). Attack was chosen because decide opens the item box list in True Survival mode (`0x552a60`).

## Settings

`RE1HD.AnnotatedMap.ini` has `Version=4`. An INI with a lower Version is rewritten once at start-up; before 3, `ItemNames` was on/off and moves on -> 1 (all), off -> 0 (hidden); before 4 there was no events group, so bit 64 of `HiddenKinds` (events, key 6) is set once. `HiddenKinds` bits are kinds, not key numbers, so the 2026-11-08 renumbering (5 puzzles, 6 events, 7 common items, 8 enemies, 9 scope, `\` language) needs no other change to saved toggles. `ItemNames` is 0 hidden, 1 all, 2 all except common items. Saving copies the INI to `.tmp`, writes the keys there and replaces the INI with it (`MoveFileExA`), so a failed write keeps the old file. `Modifier` (`Shift` or `Ctrl`) picks the key held with `- + [ ]` for icon size and opacity; `DoorKey=Unvisited` puts a lock's key in the room not visited yet instead of on the door. A lock row's two points lie 22 px either side of its door, so the default uses their midpoint.

`[Colors]` holds one `#RRGGBB` per category (`Rooms`, `Locks`, `KeyItems`, `Files`, `Puzzles`, `Events`, `CommonItems`, `Enemies`; `src/colors.h`). The draw state is `COLOROP = MODULATE (texture, diffuse)`, so a raster is tinted by its vertex colour; a legend row off is `#6A6A6A`. The save routine writes only `[AnnotatedMap]` keys into the copy, so `[Colors]`, `[CrimsonRooms]` and every comment survive (`tests/test_re3_parity.py`).

## Events

An event is a mark of kind 6 (`Synth.kind == SYN_EVENT_KIND` in `src/synth_marks.h`, hidden group 64, key 6): the purple `?` diamond (`icons[14]`), no name, hidden once its `hide_bank`/`hide_flag` bit is set. The rows are `src/event_marks.h`, generated with `data/story-events.json` and `docs/story-events.md` by `tools/build_events.py` from a decrypted bhd.exe analysis image (not committed; needs capstone) and `nativePC/arc/event`. `hide_bank` 4 = bank 0 (the story bank, flag base +4); `chr` filters by character like labels.
